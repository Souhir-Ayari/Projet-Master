# Liste des acronymes — une ligne par sigle, « SIGLE : définition ». Complétée au fil des chapitres.
ATLAS : *Adversarial Threat Landscape for Artificial-Intelligence Systems* (MITRE)
ATT&CK : *Adversarial Tactics, Techniques, and Common Knowledge* (MITRE)
CARL : *Case-based Attack Remediation for LLMs*, l'approche proposée dans ce mémoire
CBR : *Case-Based Reasoning*, raisonnement à partir de cas
CTI : *Cyber Threat Intelligence*, renseignement sur les menaces
LLM : *Large Language Model*, grand modèle de langage
RAG : *Retrieval-Augmented Generation*, génération augmentée par la recherche
